Privacy Policy

Last updated: October 23, 2026

Please read this Privacy Policy carefully before using JailBot. This Privacy Policy is subject to change at any time, and it is suggested you check it often.

Definitions

For the purposes of this Privacy Policy:

  • Text channel means a Discord text channel.
  • User means a Discord user.
  • User role means a Discord user role.
  • Guild means a Discord guild/server.

Information Collected

Per AutoMod Rule Configured:

  • ID of the guild.
  • ID of the Discord AutoMod rule to jail users on.
  • The sentence length (time) a user will be jailed when the AutoMod rule triggers.
  • For a custom sentence, the number of months, weeks, days, hours, and minutes.

Per Excluded Category:

  • ID of the guild.
  • ID of the category to exclude from jail checks.

Per Excluded Channel:

  • ID of the guild.
  • ID of the channel to exclude from jail checks.

Per Excluded Role:

  • ID of the guild.
  • ID of the role that is kept when someone is jailed.

Per Guild:

  • ID of the guild.
  • ID of the jail category that is created.
  • ID of the closed jail tickets category that is created.
  • ID of the text channel "jail-logs" that is created.
  • ID of the "create-dispute-ticket" channel that is created.
  • ID of the message prompt that is sent in the "create-dispute-ticket" channel.
  • ID of JailBot's managed role.
  • ID of the user role "Jail Inmate" that is created.
  • ID of the user role "Jail Mod" that is created.
  • Number of jail votes required for a vote to pass (set by a server admin).
  • ID of the text channel where jail votes will be sent (set by a server admin).
  • ID of the text channel where notifications are sent (set by a server admin) of who was jailed and for how long. Also known as the "general channel" or "jail notifications channel".
  • The custom regular jail notification message (if set by a server admin). This is encrypted when being stored.
  • The custom forever jail notification message (if set by a server admin). This is encrypted when being stored.
  • Whether anonymous jailing is enabled (set by a server admin).
  • Whether integrated dispute tickets are enabled (set by a server admin).
  • ID of the text channel where admin logs will be sent (set by a server admin).

Per User that is "Jailed":

  • ID of the guild they were jailed in.
  • ID of the user that was jailed.
  • ID of the jail log message that is sent in the "jail-logs" text channel.
  • Who jailed them. This is the jailer's user ID, or a label when no one person jailed them, such as a community vote or a Discord AutoMod action.
  • Whether the jailer is shown as anonymous.
  • ID of the dispute ticket channel if the jailed user creates one.
  • The date and time the user is jailed, stored in UTC.
  • The scheduled release date and time, stored in UTC, when the sentence is not forever.
  • The reason the user was jailed. This is encrypted when being stored.
  • The sentence length (time) the user will be jailed for.
  • The ID of each role removed from the jailed user, and the guild ID that role exists in. Excluded roles, integration-managed roles, the server booster role, the "Jail Inmate" role, and @everyone are not saved.

Per Past Jail, kept after the user is released, for /jail-history:

  • ID of the guild they were jailed in.
  • ID of the user that was jailed.
  • ID of the jail log message.
  • Who jailed them, using the same user ID or label stored while they were jailed.
  • Whether the jailer was shown as anonymous.
  • The date and time the user was jailed, and the date and time they were released. Both are stored in UTC.
  • The total time they spent jailed.
  • The reason the user was jailed. This is encrypted when being stored.

Jail Time Restrictions for /jail:

  • ID of the guild.
  • The maximum number of years, months, weeks, days, hours, and minutes a user can be jailed in that guild. Set by a guild admin. Includes whether the guild admin allows the "Forever" jail sentence option.

Jail Vote Time Restrictions for /start-jail-vote:

  • ID of the guild.
  • The maximum number of years, months, weeks, days, hours, and minutes a user can be jailed in that guild. Set by a guild admin. Includes whether the guild admin allows the "Forever" jail sentence option.

Per Jail Vote:

  • ID of the guild.
  • ID of the channel the vote was sent to.
  • ID of the vote message.
  • ID of the user that will be jailed if the vote passes.
  • The reason the user will be jailed if the vote passes. This is encrypted when being stored.
  • The time the user will spend in jail if the vote passes.

Per Premium Customization, when a server admin sets it:

  • ID of the guild.
  • The custom embed color.
  • The custom embed footer. This is encrypted when being stored.
  • The custom embed icon URL. This is encrypted when being stored.

Per Premium Grant or Discord Entitlement:

  • ID of the guild.
  • ID of the Discord entitlement and its SKU, for entitlements that are created, deleted, or refunded.
  • For free premium granted by the bot operator: the premium level, how many months were given, the expiration date, and any notes entered with that grant.

Per Command Announcement. One announcement is stored for the bot, not one per server:

  • ID of the guild where the announcement was saved.
  • The announcement text, an optional footer, an optional image URL, and up to two optional links.
  • Whether the announcement is a Top.gg vote reminder, whether it is marked important, a goal amount, and a goal description.
  • ID of the guild and ID of the user for each person who has already been shown a one-time announcement. These view records are removed when a new announcement is saved. An important announcement, and a Top.gg vote reminder, do not record who has seen it.

Per Server Banned from Using JailBot:

  • ID of the guild.
  • The reason the bot operator entered.

Anonymous Statistics:

  • The total number of servers per day that JailBot is in.
  • The number of premium servers per day.
  • The number of servers JailBot has been added to and removed from each day.
  • The number of times each command has been run per day. This count is not tied to a user or a guild.
  • The median and maximum member counts for servers that JailBot is in.

Buy Me a Coffee totals are kept only as three numbers: money received in the current month, the number of active memberships, and the number of unique one-time donors this month. Donor names, email addresses, and messages are not stored.

How Collected Information is Used

Collected identifiable information is used to support the bot's functionality. Anonymous statistics are aggregated counts and cannot be traced back to any guild or user identifiers. Collected information is not sold. Guild configuration, active jails, and jail history (for the /jail-history command/feature) are saved until a data deletion request is made.

JailBot sends its total server count to Top.gg. To decide whether to show a command announcement, JailBot may send that person's Discord user ID to Top.gg and ask whether they have voted. It does this for a Top.gg vote reminder, unless that server's premium status already hides the reminder, and for an ordinary announcement the person has not already seen on a server that is not premium. It does not do this for an important announcement. The vote result is not saved.

Request Deletion of Information

Email jailbot.support@meta-dev.net to request deletion of your guild's saved information. Please include the ID of your guild. Get this by first enabling developer mode, then right-clicking on your server and selecting "Copy Server ID". You will then be asked to verify your data deletion request via Discord DMs to ensure you are the server owner.
